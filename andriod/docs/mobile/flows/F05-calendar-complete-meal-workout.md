# F05 — Calendar Complete Meal / Workout

1. Open Calendar — month/week with workout/nutrition dots  
2. Select day → DayDetail: workout entries + meal groups  
3. Toggle workout activity → `toggleTask` / activity completion persist  
4. Toggle meal group → `toggleMealCompletion(dateStr, mealType, entryIds)`  
5. State in member completedActivities / activities data  

Package windows: entries outside package may be read-only or warned (`programPackageScope`).
